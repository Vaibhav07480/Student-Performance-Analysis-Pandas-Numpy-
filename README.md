# Student Performance Analysis

A beginner-level data analysis project using Python.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## About

In this project, I explored a student performance dataset using Pandas and NumPy. I looked at basic information about the data and created a few visualizations using Matplotlib.

Some of the things I explored include student scores, attendance, study hours and grades.

## What I Learned

* Loading and exploring CSV data
* Using Pandas for data analysis
* Using NumPy for basic calculations
* Creating simple graphs with Matplotlib
* Working with data in Jupyter Notebook

This is a beginner project and I will continue improving it as I learn more.
